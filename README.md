# Vista previa de la tienda (nombre provisional)

Copia estática y navegable del diseño y del catálogo de una tienda B2B de recambios de móvil para talleres.
Solo contiene páginas generadas, sus imágenes y los archivos del navegador: ni código fuente, ni base de datos, ni datos de clientes.
Los pedidos, la cuenta y la búsqueda instantánea funcionan en la tienda instalada, no en esta vista previa.
